# 🎧 K-Pop Fan AI Helper

面向中韩 K-Pop 粉丝的轻量级 AI Agent 网页 Demo。一站式完成 **应援文案生成 / 韩娱短文本翻译 / 偶像资讯问答** 三大高频粉丝场景。

> ⚠️ 本项目为 **前端产品验证 Demo**：不实现私有 RAG 知识库、不做账号登录系统、不包含自建后端服务。大模型能力通过外部公开 API 调用，密钥放在环境变量中，**不提交仓库**。

## ✨ 核心亮点
- **韩系简约 UI**：奶油白底 + 柔和粉紫渐变、窄栏居中布局、圆角气泡，适配海外年轻 C 端审美
- **场景快捷 Prompt 按钮**：应援文案 / 韩娱翻译 / 偶像问答，一键填入问题，降低输入门槛
- **对话本地收藏**：收藏喜欢的人机对话到 `localStorage`，支持查看 / 复制 / 取消收藏
- **Mock 兜底**：未配置 API Key 也能在任何环境（本地 / GitHub Pages 在线）演示，不泄露密钥

## 🎯 目标用户分析
| 用户画像 | 使用场景 | 核心需求 |
| --- | --- | --- |
| 追星学生 / 年轻上班族（中韩） | 偶像生日、回归、演唱会应援 | 快速产出个性化应援文案 |
| 韩娱内容消费者 | 刷到韩语短推文、预告、歌词 | 自然流畅的短文本翻译 |
| 新入坑粉丝 | 不了解偶像团体、回归信息 | 快速问答式科普 |

核心洞察：粉丝内容创作（应援）与即时理解（翻译）都是 **高频、轻量、即时** 的需求，轻量 Web Agent 恰好匹配。

## 🧩 核心功能
1. 应援文案生成：输入偶像 / 场合，生成韩系风格应援文案（含 hashtag）
2. 韩娱短文本翻译：中韩互译，保留粉丝语境与语气
3. 偶像资讯问答：基于外部大模型开放能力的单轮问答
4. 快捷 Prompt 按钮：三大场景一键唤起，降低首用门槛
5. 对话收藏：收藏人机对话到 localStorage，可查看 / 复制 / 取消

## 🆚 竞品分析摘要
| 竞品 | 定位 | 本项目差异点 |
| --- | --- | --- |
| ChatGPT / DeepSeek 通用对话 | 通用大模型对话 | 聚焦粉丝场景，提供快捷 Prompt 降低门槛 |
| 应援语生成器（小程序/网页） | 单一文案模板工具 | 支持翻译 + 问答的 Agent 形态，而非静态模板 |
| 翻译工具（Papago/DeepL） | 通用翻译 | 保留粉丝语境、结合偶像/回归场景的翻译 |

## 🛠 技术栈
- **Vue 3 + Vite**（极简结构，无重型 UI 库 / 状态管理依赖，逻辑清晰）
- 大模型：外部公开 API（OpenAI 兼容接口，DeepSeek / 豆包 / SiliconFlow 等，在 `.env` 配置）
- 本地存储：`localStorage`（收藏功能，无后端）
- 部署：GitHub Pages（GitHub Actions 自动构建发布）

## 🚀 本地运行
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 产物在 dist/
```

## 📖 部署说明（GitHub Pages）
1. 将本仓库推送到 GitHub（`main` 分支），仓库名需与 `vite.config.js` 的 `base` 一致
2. 仓库 → Settings → Pages → Source 选 **GitHub Actions**
3. 推送后 Actions 自动构建 `dist` 并发布，访问 `https://<账号>.github.io/<仓库名>/`
4. `.env` 已加入 `.gitignore`，**切勿提交真实密钥**

> 🔒 安全提醒：纯前端构建会把 `.env` 内联进产物。在线 Demo 请保持 Mock 模式（不填密钥），或只用受限 / 低成本测试密钥。
